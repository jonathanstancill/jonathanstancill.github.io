02 / Independent computational work

Fuel-system pressure-loss analysis

I independently wrote both Python and MATLAB implementations of a pressure-loss calculation for the piping between a fuel tank and injector system. The calculation combines Darcy–Weisbach frictional losses in straight pipes with the 3K method for fitting losses.

The program estimates total pressure drop for specified fluid properties, pipe dimensions, flow velocity, Reynolds number, and fitting coefficients. The results contributed to a broader design effort to determine fuel tank requirements and charging pressure, with a goal of supporting 10 seconds of burn time while keeping system weight low.

Modeling approach

1. Straight-pipe loss: Calculate frictional head loss with the Darcy–Weisbach equation.

hf = f (L / D) · V² / (2g)

2. Fitting loss: Estimate each fitting's loss coefficient using the 3K method, then calculate its corresponding head loss.

K = K₁ / Re + K∞ [1 + Kd / D0.3]
hm = K · V² / (2g)

3. System pressure drop: Sum the head losses and convert to pressure.

ΔP = ρg · Σhloss

Implementation

Both versions use separate functions for straight-pipe head loss and 3K-based fitting head loss, then sum the contributions. The code allows fitting types and quantities to be represented through their associated coefficients and repeated calculations.

# Core calculation (simplified excerpt)
straight_loss = f * (L / D) * (V**2 / (2*g))
K = K1 / Re + K_inf * (1 + K_d / (D_nom**0.3))
fitting_loss = K * (V**2 / (2*g))
pressure_drop_pa = rho * g * (straight_loss + total_fitting_loss)

The downloadable versions preserve the original calculation logic and sample input values. They are example-driven calculation scripts, not a complete automated tank-mass optimizer or a validated fuel-system design.

Technical note: pressure-loss results inform charging-pressure and tank-size decisions, but this code alone does not calculate minimum system mass or independently establish a tank sized for 10 seconds of operation. Inputs and 3K coefficient units should be checked against the intended physical configuration before using its numerical output for design.

03 / Aircraft geometry

Parametric wing design in nTop

I used nTop to create and modify wing geometry through a parametric modeling workflow as part of GT Supersonics' aircraft design work. This introduced an approach to designing aircraft geometry in which parameters can be adjusted to support successive iterations without rebuilding every feature from scratch.

The work complements my propulsion experience by developing familiarity with computational geometry tools used in early aircraft design.

Reflection

What this work has taught me

These projects have reinforced that successful aerospace design depends on understanding how individual components affect the larger system. In the fuel analysis, piping losses influenced questions about tank pressure and weight. In the afterburner, flameholding, injection, and ignition must be considered together. Working across these areas has strengthened my interest in combining analytical work with practical aerospace design.
